# Sanders Mutsimba — Technical Portfolio

A multi-page portfolio for SHEQ, environmental management and GIS work.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `sanders-mutsimba-portfolio`).
2. Upload the contents of this folder to the repository root — keep `index.html` at the root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

All styles, images and the CV are stored locally in `assets/`; no build step is required.
